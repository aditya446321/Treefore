How it works
  1. Input: paste tree output, write your own with the helper buttons, or upload a folder.
  2. Preview: check the structure. A name ending in /, or with items under it, is a folder.
  3. ZIP: download the whole structure in one click.
  4. GitHub: connect once with a token. It stays saved until GitHub says it expired. Pick or create a repo and everything is pushed. Empty repos are set up automatically.
Writing a tree correctly
✅ Right
my-app/
├── src/
│   └── main.js
└── README.md
✅ Also right (plain indent)
my-app/
    src/
        main.js
    README.md
  • Folder: end the name with / (src/). File: no slash (main.js).
  • Items inside a folder go one level deeper. Use the same step every time (4 spaces, or Tab).
  • Not allowed in names: : * ? " < > |. Use /, never \, between folders.
  • Wrote something wrong? A yellow box shows the line and how to fix it. Tap it to jump there, or press Fix.
