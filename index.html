What TreeForge does

TreeForge turns a folder tree into real files. Paste the output of the tree command, write your own structure with the helper buttons, or drop in an existing folder. You get a preview of every folder and file, then you can download everything as a ZIP or push it to a GitHub repository in a single flow.

It is made for scaffolding a new project from a plan, copying a structure that someone shared in a README or chat, and uploading a folder to GitHub from a phone where Git is not available.

How it works

  1. Add your tree. Paste it, type it, or upload a folder. Mistakes are highlighted with a plain explanation of how to fix them.
  2. Check the preview. Folders and files are listed with counts. Empty folders can keep a .gitkeep, and a README and .gitignore can be added for you.
  3. Ship it. Download a ZIP, or connect GitHub once, choose a repository or create a new one, and push.

Supported tree formats

Folders end with /, files do not, and anything indented under a folder belongs inside it. Both of these produce the same result:

my-app/
├── src/
│   └── main.js
└── README.md
my-app/
    src/
        main.js
    README.md

File names cannot contain : * ? " < > |. Use /, not a backslash, between folders.

Privacy

TreeForge runs entirely in your browser and has no server of its own. Your tree, your files and your GitHub token are never sent to us. A token is kept in your browser's local storage so you stay connected, and you can disconnect at any time from the account button in the header.

Frequently asked questions

Is TreeForge free?

Yes. TreeForge is free, needs no sign-up and has no usage limits. Everything runs in your browser.

Are my files or my GitHub token sent to your server?

No. TreeForge has no backend. Files are built in your browser. When you push, requests go directly from your browser to api.github.com. Your token is stored only on your own device and stays there until GitHub rejects it or you disconnect.

What permissions does the GitHub token need?

For a classic token, the repo scope. For a fine-grained token, Contents with Read and write access to the repository you want to push to.

Can I push to an empty repository?

Yes. An empty repository is detected automatically and set up for you. Because GitHub needs a first commit before bulk uploads work, an empty repo receives two commits: the first file, then the rest.

Which tree formats can I paste?

Output of the tree command (├── └── │), ASCII trees (+-- and |--), bullet lists, and plain indented lists with 2, 3 or 4 spaces. End a name with / to mark a folder.

Is there a file size limit?

When you upload a folder, files over 100 MB are skipped. .git, node_modules and .DS_Store are ignored automatically. GitHub's own limits also apply to pushes.

Writing a tree correctly
✅ Right
my-app/
├── src/
│   └── main.js
└── README.md
✅ Also right (plain indent)
my-app/
    src/
        main.js
    README.md
  • Folder: end the name with / (src/). File: no slash (main.js).
  • Items inside a folder go one level deeper. Use the same step every time (4 spaces, or Tab).
  • Not allowed in names: : * ? " < > |. Use /, never \, between folders.
  • Wrote something wrong? A yellow box shows the line and how to fix it. Tap it to jump there, or press Fix.
